# ArcTV — дополнения Home Assistant

Репозиторий дополнений Home Assistant для проекта «Наталкин Кинозал» (ArcTV).

**Установка:** Настройки → Дополнения → Магазин дополнений → ⋮ → Репозитории →
`https://github.com/MrCheng888/arctv-ha` → Добавить → «Наталкин Кинозал (ArcTV)» → Установить.

| Дополнение | Что |
|---|---|
| [arctv](arctv) | Домашний сервер IPTV для телевизоров Samsung (Tizen и Orsay), порт 18090 |
