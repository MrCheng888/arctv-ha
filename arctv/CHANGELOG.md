# Изменения

## 0.8.2
- Домофон: новое событие `dismiss` — сброс вызова с телефона или домофона убирает красные кнопки на телевизорах сразу, окно с камерой остаётся ещё 10 секунд; повторный звонок возвращает кнопки.

## 0.8.1
- **Камеры**: плитка «Камеры» — последняя на экране групп у телевизоров с флажком «Камеры»; внутри — плитки камер (онлайн/офлайн), камера на весь экран, ◀ ▶ — переключение. Список camera.* сервер берёт из Home Assistant сам; на странице сервера раздел «Камеры»: галочки, имена, порядок, частота кадров (1–10), «Снимок», удаление пропавших из HA, «Обновить список». Кадры тянутся из HA только пока кто-то смотрит.
- Домофон: открыть дверь — только зелёная кнопка (подтверждение «Нажмите ещё раз» с зелёным кружком); OK окно не трогает.

## 0.8.0
- Домофон: после «Сбросить вызов» следующий звонок снова показывает кнопки «открыть / сбросить» (статус прежнего вызова очищается при каждом звонке).
- Домофон: настройка «Кадров в секунду» (0–10; 0 — окно без картинки), телевизоры подстраиваются сами.
- Страница сервера: справка по Home Assistant в разделе «Домофон» убрана под «Информация».

## 0.7.9
- Домофон: звонок в дверь (сигнал от Home Assistant на `POST /doorbell?key=…`) — окно с картинкой с камеры поверх эфира на телевизорах с флажком «Домофон»; с пульта — открыть дверь (с подтверждением), сбросить вызов, скрыть окно. Доступ к API Home Assistant — собственный доступ дополнения (`homeassistant_api`). Раздел «Домофон» на странице сервера: сущности, снимок с камеры, проверка, готовые строки для HA.

## 0.7.7
- Страница сервера внутри Home Assistant (Ingress): кнопка «Открыть веб-интерфейс» и пункт ArcTV в боковом меню, без второго пароля. По прямому адресу :18090 — вход по логину и паролю, как раньше.
- Адреса на странице относительные (работают и по прямому адресу, и внутри HA).

## 0.7.5.3
