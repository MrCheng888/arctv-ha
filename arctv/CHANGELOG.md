# Изменения

## 0.8.8
- Домофон: после сброса вызова (с телевизора, телефона или панели) дверь можно открыть, пока окно открыто: статус «Открываю дверь…» заменяет «Вызов сброшен», и окно закрывается через 5 с. Сброс «Открываю дверь…» не перетирает. Нужно приложение 0.8.8 (зелёная остаётся на окне после сброса).

## 0.8.5
- Камеры: поток кадров из 0.8.4 убран — через прокси Supervisor поток MJPEG не идёт (кадров нет, снимки сада при этом не успевали за 6 с). Камеры — снимками, как в 0.8.3. Окно домофона (5 с после открытия, 10 с после сброса) — остаётся.

## 0.8.4
- Камеры: у камер с медленным снимком (дольше 1 с — сад, Dahua IPC-HFW1230S: 3–5 с на кадр) сервер, пока камеру смотрят, держит открытым поток MJPEG из Home Assistant (`/camera_proxy_stream`) и отдаёт телевизорам последний кадр — частота как в настройке «Кадров в секунду», а не 1 кадр в 3–4 с. Первые ~3–7 с — снимок, пока поток разгоняется. Через 8 с без просмотра поток закрывается. Быстрые камеры (вход) — снимками, как раньше. Поток не работает — снимки.
- Домофон: после открытия двери (не с телевизора) окно закрывается через 5 с, после сброса — через 10 с.

## 0.8.3
- Домофон: событие `dismiss` от Home Assistant — вызов сброшен или дверь открыта не с телевизора (телефон, домашняя панель): на всех телевизорах кнопки сразу пропадают («Вызов сброшен», с `reason: open` — «Открываю дверь…»), окно с камерой закрывается через 10 с; повторный звонок возвращает кнопки. Статус, поставленный кнопкой с телевизора, не перетирается. `dismiss` присылается **отдельным действием** — `ring` и `end` в автоматизации остаются как были (0.8.2 откачен из-за их замены).
- `/api/door/test` понимает `{event: "dismiss"}`.

## 0.8.1
- **Камеры**: плитка «Камеры» — последняя на экране групп у телевизоров с флажком «Камеры»; внутри — плитки камер (онлайн/офлайн), камера на весь экран, ◀ ▶ — переключение. Список camera.* сервер берёт из Home Assistant сам; на странице сервера раздел «Камеры»: галочки, имена, порядок, частота кадров (1–10), «Снимок», удаление пропавших из HA, «Обновить список». Кадры тянутся из HA только пока кто-то смотрит.
- Домофон: открыть дверь — только зелёная кнопка (подтверждение «Нажмите ещё раз» с зелёным кружком); OK окно не трогает.

## 0.8.0
- Домофон: после «Сбросить вызов» следующий звонок снова показывает кнопки «открыть / сбросить» (статус прежнего вызова очищается при каждом звонке).
- Домофон: настройка «Кадров в секунду» (0–10; 0 — окно без картинки), телевизоры подстраиваются сами.
- Страница сервера: справка по Home Assistant в разделе «Домофон» убрана под «Информация».

## 0.7.9
- Домофон: звонок в дверь (сигнал от Home Assistant на `POST /doorbell?key=…`) — окно с картинкой с камеры поверх эфира на телевизорах с флажком «Домофон»; с пульта — открыть дверь (с подтверждением), сбросить вызов, скрыть окно. Доступ к API Home Assistant — собственный доступ дополнения (`homeassistant_api`). Раздел «Домофон» на странице сервера: сущности, снимок с камеры, проверка, готовые строки для HA.

## 0.7.7
- Страница сервера внутри Home Assistant (Ingress): кнопка «Открыть веб-интерфейс» и пункт ArcTV в боковом меню, без второго пароля. По прямому адресу :18090 — вход по логину и паролю, как раньше.
- Адреса на странице относительные (работают и по прямому адресу, и внутри HA).
